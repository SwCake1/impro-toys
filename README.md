# Impro Toys

Небольшой набор инструментов для импровизации, репетиций и сценических игр.

В проекте есть генераторы слов, эмоций, локаций, отношений, первых реплик и тем для рэп-батлов, а также интерактивный звонок.

## Запуск

Сборка и установка зависимостей не нужны. Откройте `index.html` в браузере:

```bash
open index.html
```

Сайт работает напрямую через `file://` и может размещаться на GitHub Pages.

## Структура

```text
index.html       # каталог инструментов
tools/           # отдельная папка для каждого инструмента
shared/          # общие стили, скрипты и ресурсы каталога
docs/            # архитектурные заметки
openspec/        # требования и описания изменений
deploy.sh        # публикация текущей ветки в main
```

Каждый инструмент хранит свою разметку, стили, логику и данные внутри `tools/<название>/`.

## Публикация

Перед публикацией проверьте, что изменения закоммичены и рабочая директория чистая, затем запустите:

```bash
./deploy.sh
```

Скрипт обновит локальную ветку `main`, объединит с ней текущую ветку и отправит результат в `origin/main`.
