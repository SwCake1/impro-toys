## Why

Новый набор театральных миниатюр выразителен, но его стиль подходит не каждому пользователю и может спорить с визуальным языком отдельных инструментов. Каталог должен позволять вернуться к исходным лаконичным иконкам и запоминать этот выбор между посещениями.

## What Changes

- В шапке каталога появляется доступная кнопка настроек.
- Настройки предлагают два набора иконок: исходные «Классические» SVG и новые «Театральные» WebP.
- Выбранный набор применяется ко всем семи карточкам сразу с короткой визуальной реакцией.
- Выбор сохраняется локально в браузере и восстанавливается при следующем открытии каталога.
- При недоступном хранилище каталог продолжает работать с театральным набором по умолчанию.

## Capabilities

### New Capabilities

- `catalog-icon-theme-selection`: выбор, применение и локальное сохранение набора иконок каталога.

### Modified Capabilities

Нет.

## Impact

Изменяются `index.html` и `shared/styles.css`, добавляется небольшой `shared/catalog.js`, а также новый OpenSpec-контракт. Серверная часть, cookie, внешние библиотеки и сетевые API не требуются.
