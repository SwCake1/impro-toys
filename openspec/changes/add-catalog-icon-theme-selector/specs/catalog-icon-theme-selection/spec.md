## ADDED Requirements

### Requirement: Пользователь выбирает набор иконок каталога
Каталог SHALL предоставлять настройку с вариантами «Классические» и «Театральные». Выбранный вариант MUST применяться ко всем карточкам инструментов без перезагрузки страницы.

#### Scenario: Пользователь выбирает классические иконки
- **WHEN** пользователь выбирает вариант «Классические»
- **THEN** все карточки каталога отображают соответствующие исходные SVG-иконки

#### Scenario: Пользователь выбирает театральные иконки
- **WHEN** пользователь выбирает вариант «Театральные»
- **THEN** все карточки каталога отображают соответствующие сгенерированные WebP-иллюстрации

### Requirement: Выбор набора сохраняется между посещениями
Каталог SHALL сохранять выбранный набор в локальном хранилище браузера и MUST восстанавливать допустимое сохранённое значение при следующем открытии страницы.

#### Scenario: Пользователь возвращается в каталог
- **WHEN** в локальном хранилище находится допустимое ранее выбранное значение
- **THEN** каталог применяет соответствующий набор ко всем карточкам и отмечает его в настройках

#### Scenario: Сохранённого выбора нет
- **WHEN** допустимое сохранённое значение отсутствует
- **THEN** каталог использует театральный набор по умолчанию

#### Scenario: Локальное хранилище недоступно
- **WHEN** браузер запрещает чтение или запись локального хранилища
- **THEN** пользователь всё ещё может переключить набор в текущем открытии без поломки каталога

### Requirement: Настройка доступна на поддерживаемых устройствах
Кнопка настроек и варианты набора MUST работать с клавиатурой, указателем и касанием. Диалог MUST иметь понятное название, видимый способ закрытия и видимое состояние фокуса.

#### Scenario: Пользователь открывает настройку с клавиатуры
- **WHEN** фокус находится на кнопке настроек и пользователь активирует её стандартным способом
- **THEN** открывается подписанный диалог, в котором доступны оба варианта и кнопка закрытия

#### Scenario: Пользователь открывает настройку на телефоне
- **WHEN** пользователь касается кнопки настроек на мобильной ширине
- **THEN** диалог помещается в область просмотра и варианты остаются удобными для касания
