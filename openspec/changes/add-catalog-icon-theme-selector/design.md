## Context

Каталог уже содержит два полных локальных набора: исходные SVG в `shared/assets/` и театральные WebP в `shared/assets/catalog-generated/`. Страница статическая, работает без сервера и сборки; настройка относится только к текущему браузеру и не требует синхронизации между устройствами.

## Goals / Non-Goals

**Goals:**

- Дать понятный выбор между двумя наборами без перегрузки главного экрана.
- Применять выбор ко всем карточкам одновременно и восстанавливать его при следующем открытии.
- Сохранить поддержку клавиатуры, касания, мобильной сетки и `file://` настолько, насколько браузер предоставляет локальное хранилище.

**Non-Goals:**

- Аккаунтная или серверная синхронизация настройки.
- Загрузка пользовательских изображений или создание произвольных тем.
- Изменение дизайна страниц инструментов.

## Decisions

- Использовать `localStorage` с ключом `impro-toy.catalog.icon-theme` и значениями `classic` / `theatrical`. Cookie не используется: значение не нужно серверу, а сайт должен оставаться полностью статическим.
- Театральный набор остаётся значением по умолчанию, поскольку это текущий вид каталога. Неизвестное или повреждённое значение игнорируется.
- Каждый основной `<img>` хранит оба относительных URL в `data-*`; JavaScript меняет только `src`. Это сохраняет семантику и не дублирует изображения в DOM.
- Настройки открываются нативным `<dialog>` с двумя radio-вариантами и визуальными образцами. Нативный элемент обеспечивает Escape, удержание фокуса и возврат фокуса на кнопку.
- Выбор применяется немедленно, без отдельной кнопки сохранения. Короткая анимация смены затрагивает только иконки и отключается при `prefers-reduced-motion`.
- Все обращения к хранилищу оборачиваются в `try/catch`: при запрете или недоступности storage переключение продолжает работать до перезагрузки.

## Risks / Trade-offs

- [Поведение `localStorage` для `file://` зависит от браузера] → корректно обрабатывать исключение и сохранять работоспособный выбор в текущем открытии; на GitHub Pages сохранение стабильно привязано к origin.
- [При восстановлении классического набора возможна короткая смена картинки] → подключить скрипт с `defer` и применить сохранённое значение сразу после разбора DOM.
- [Диалог добавляет визуальный слой в спокойный каталог] → сделать кнопку вторичной, а панель компактной и предметно связанной с выбором реквизита.
