## Context

Сайт состоит из независимых статических инструментов без сборщика и внешних зависимостей. Новый генератор должен работать через `file://`, GitHub Pages, клавиатуру, указатель и касание, а его собственный визуальный язык не должен переноситься в общие стили.

## Goals / Non-Goals

**Goals:**

- Выдавать русские буквы быстро, без повторов до исчерпания активного набора.
- Дать понятные режимы алфавита и безопасное поведение при изменении фильтров.
- Создать самостоятельный адаптивный интерфейс типографской кассы с одной выразительной анимацией и коротким звуковым откликом.
- Сохранить доступность, относительные пути и работоспособность при недоступном Web Audio.

**Non-Goals:**

- Сохранение настроек между посещениями.
- Серверные API, аналитика, внешние шрифты или аудиофайлы.
- Изменение визуального языка существующих инструментов и каталога.

## Decisions

- Алфавит и классификация хранятся локально в JavaScript: 33 прописные буквы, 10 гласных с `Ё`, 21 согласная; `Ъ` и `Ь` не входят ни в одну звуковую группу. Это прозрачнее внешнего файла для небольшого неизменяемого набора.
- Активные буквы перемешиваются алгоритмом Фишера — Йетса и извлекаются из колоды. При смене настройки колода строится заново; если предыдущая буква ещё допустима и есть альтернатива, она не становится первой в новой колоде.
- Быстрые действия складываются в очередь. Один цикл показывает декоративные промежуточные литеры, затем ровно один финальный результат, обновляет `aria-live` и запускает следующий ожидающий цикл.
- Настройки представлены нативным `dialog`, визуально оформленным как выдвижной ящик. Режим — взаимоисключающие radio-кнопки, исключение `Ы`, `Ъ`, `Ь` — отдельный checkbox; значения применяются сразу, но не записываются в хранилище.
- Звук синтезируется одним лениво созданным `AudioContext`: короткий фильтрованный шум имитирует деревянный удар, осциллятор — металлический щелчок. Любая ошибка аудио перехватывается и не влияет на результат.
- Визуальная подпись инструмента — физический литерный блок с несовмещённым красочным оттиском. Палитра ограничена чернильно-синим, бумажно-фиолетовым, мандариновым, бирюзовым и приглушённым синим; основной интерфейс остаётся спокойным вокруг центрального механизма.
- `prefers-reduced-motion` отключает прокрутку и встряску, оставляя короткое затухание результата. Все кнопки используют `touch-action: manipulation`.
- Карточка «Буквы» располагается сразу после «Слов» и использует один локальный SVG-идентификатор без тематических растровых вариантов.

## Risks / Trade-offs

- [Большая очередь после серии частых нажатий задержит последние результаты] → цикл остаётся коротким, а кнопка показывает число ожидающих действий без потери нажатий.
- [Web Audio запускается только после пользовательского жеста и может быть недоступен] → контекст создаётся при генерации, ошибки подавляются, визуальный результат всегда продолжается.
- [Поведение нативного `dialog` различается в старых браузерах] → предусмотреть fallback через атрибут `open`, явное закрытие и возврат фокуса.
- [Новая карточка может нарушить визуальный ритм каталога] → использовать лаконичный SVG в существующей классической пластике и проверить ровную сетку из восьми карточек.
