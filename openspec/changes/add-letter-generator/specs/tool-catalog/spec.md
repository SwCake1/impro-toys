## ADDED Requirements

### Requirement: Каталог запускает генератор букв
Каталог SHALL представлять реализованный генератор букв полноразмерной карточкой `Буквы` с локальной SVG-иконкой, расположенной рядом с карточкой `Слова`, и MUST сохранять адаптивную сетку для восьми инструментов.

#### Scenario: Пользователь открывает генератор букв
- **WHEN** пользователь активирует любую видимую область карточки `Буквы`
- **THEN** браузер переходит по относительной ссылке на `tools/letters/index.html`

#### Scenario: Каталог содержит восемь инструментов
- **WHEN** каталог открыт на широком экране или телефоне
- **THEN** восемь карточек образуют ровные ряды при четырёх колонках на достаточно широком экране и двух колонках на телефоне
