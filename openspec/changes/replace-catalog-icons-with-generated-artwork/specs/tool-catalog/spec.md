## MODIFIED Requirements

### Requirement: Доступные инструменты представлены запускаемыми карточками
Каталог SHALL представлять каждое доступное мини-приложение в виде карточки, вся видимая область которой служит ссылкой на инструмент. Каждая карточка MUST содержать название инструмента и собственную выразительную иллюстрацию из согласованного набора тактильных театральных миниатюр. Иллюстрация MUST оставаться различимой в адаптивной сетке и SHALL загружаться локально по относительному URL без сетевого запроса к генератору изображений.

#### Scenario: Пользователь открывает доступный инструмент
- **WHEN** пользователь активирует любую область карточки доступного инструмента
- **THEN** браузер переходит на отдельную страницу этого инструмента

#### Scenario: Каталог содержит только реализованные инструменты
- **WHEN** отображается каталог
- **THEN** в нём присутствуют запускаемые карточки только тех инструментов, страницы которых уже доступны

#### Scenario: Каталог отображает новый визуальный набор
- **WHEN** загружается главная страница каталога
- **THEN** каждая из семи карточек показывает соответствующую локальную растровую иллюстрацию без фона и сохраняет читаемую подпись инструмента

#### Scenario: Каталог открыт локально
- **WHEN** главная страница открыта через `file://`
- **THEN** все иллюстрации загружаются по относительным путям без внешних зависимостей
